# Trading Games

Small browser games for practicing trading skills: pricing odds, spotting edge and sizing bets.
It's a static site with no server and no build: open `index.html` in a browser, or host the folder (e.g. on GitHub Pages).

- **Betting Board**: find the mispriced lines on a board of coin, dice, card, integer, roulette and urn bets,
  stake them, and compare your sizing with Kelly.

Conventions and how to add markets or games are in [CLAUDE.md](CLAUDE.md).
